# Data Card

- **IMF PortWatch:** Satellite-derived daily port activity tracking calls and volumes.
- **GDACS:** Near real-time geospatial alerts for natural disasters.
- **UNCTAD LSCI / World Bank LPI:** Connectivity and macro-economic infrastructural benchmarks.

**Note on Synthetic Data:** In demo or test mode, the data generation scripts synthesize relationships honoring natural distributions. Do not interpret demo mode data as real-world facts.
